# Support

For help, search or open an issue in
[digimangos/repowise-markitdown-plugin](https://github.com/digimangos/repowise-markitdown-plugin/issues).
Support is provided on a best-effort basis, with no guaranteed response time.

Include your operating system, Python, Repowise, plugin and MarkItDown versions,
the command you ran, expected behaviour and sanitised output from
`repowise plugins`. Use a minimal synthetic PDF rather than a confidential source.

If PDFs are missing, first confirm the plugin is installed in Repowise's Python
environment, is loaded and claims `.pdf`. Check Git tracking, ignore rules and
host size limits. Scanned PDFs require a separate OCR step. See the
[README limitations](README.md#limitations).

Host discovery, indexing and dashboard issues belong in
[Repowise](https://github.com/digimangos/repowise/issues); PDF conversion defects
may belong in [MarkItDown](https://github.com/microsoft/markitdown/issues).
Include a link when an issue is related across projects.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening an issue.
